## 三、版本路线图

### V1（MVP，3个月）—— 能跑通核心

**目标：** 邵逸夫急诊科试点，10-15个学员能用起来

**功能：**
- 微信小程序：文字问诊 + 5个急诊病例 + 7维度评分报告
- Web老师端：学员列表 + AI评分复核 + 班级基础看板
- 底座：PatientSim换DeepSeek/Qwen，跑通中文对话

**对标差距：** 只做了问诊环节，语音/病情动态/多角色都没有

### V2（6个月）—— 补齐核心体验差距

**目标：** 真正像国际产品，学员用起来有真实感

**新增：**
- 语音问诊（FunASR + ChatTTS）
- 病情动态演变（时间轴状态机）
- 扩展到15个病例（覆盖急诊常见病）
- 实时过程提示（问诊中适时引导）
- 全流程OSCE：加查体+处置环节

**对标：** 追平Body Interact和PatientSim的核心体验

### V3（12个月）—— 完整OSCE训练平台

**目标：** 覆盖住培全流程，成为基地标配

**新增：**
- 多角色对话（家属/护士/医生团队）
- 苏格拉底式导师反馈（不是只给分，而是引导思考）
- 30+病例，多专科扩展
- 自适应难度
- 班级/机构学习分析平台
- 考试模式（模拟结业考核）
- 病例编辑工具（带教老师可以自己写病例）

**对标：** 追平Osmosis + Socratic AI + MedSimAI的完整能力

### V4（18个月+）—— 生态与出海

**新增：**
- VR/数字人试点
- 真实病例脱敏生成
- 多院区/多基地版本
- 出海英文版（同一套引擎）

## 四、跟国际产品的核心差异（我们的独特性）

国际产品做不到的，我们要做出来：

| 差异点 | 国际产品 | 我们 |
|--------|---------|------|
| **中国住培OSCE考纲对齐** | 用MIRS国际量表，不对接中国考核 | 完全对齐中国住培三考站标准 |
| **微信生态** | Web端为主 | 小程序优先，微信登录/推送 |
| **中国病例库** | 西方人群、MIMIC数据 | 中国常见病、急诊场景 |
| **等保三级合规** | 符合HIPAA | 符合中国数据安全法 |
| **基地管理工作流** | 个人学习工具 | 贴合中国住培基地的教学管理流程 |
| **价格模式** | 贵（Osmosis $399/年） | 基地免费，药企赞助 |
