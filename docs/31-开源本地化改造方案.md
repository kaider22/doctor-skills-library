# 住培AI OSCE训练系统 · 开源本地化改造方案

> **版本：** v1.0
> **日期：** 2026-10-19
> **思路：** 不造轮子，基于开源项目做中国本地化，把精力放在差异化上

---

## 一、为什么选开源做底座

| 维度 | 从零做 | 基于开源二次开发 |
|------|--------|----------------|
| 开发周期 | 6-12个月 | 1-3个月 |
| 技术风险 | 高（病人对话质量难保证） | 低（已被顶会验证） |
| 人力成本 | 需NLP/医疗AI团队 | 只需后端+前端+医学顾问 |
| 差异化 | 全是基础功能 | 集中在本地化和教学管理 |

**结论：** 病人对话生成这种"硬骨头"，开源已经啃完了。我们要做的是把它改造成"中国住培版"。

---

## 二、选哪个开源项目做底座

### 2.1 主底座：PatientSim（NeurIPS 2025）

**为什么选它：**
- 顶会论文验证，技术成熟
- 开源（GitHub: dek924/PatientSim）
- 基于Llama 3.3，可换国产模型
- 从MIMIC-IV生成病人画像，37种人格组合
- 支持多维度行为模拟（性格/语言水平/病史回忆/认知混乱）

**它已经做好的：**
- ✅ 病人对话生成（LLM驱动）
- ✅ 多人格行为差异
- ✅ 病情逻辑推演
- ✅ 隐私合规环境（虚拟病人，不碰真实患者）

### 2.2 评分参考：MedSimAI + Socratic AI

**参考它们做什么：**
- MedSimAI：用MIRS（Master Interview Rating Scale）做自动评估——我们对齐中国OSCE评分表
- Socratic AI：实时反馈临床推理过程——我们改成"问诊过程中提示薄弱点"

### 2.3 语音底座：开源ASR/TTS

- ASR：FunASR（阿里开源，中文医疗场景优化）
- TTS：ChatTTS / GPT-SoVITS（多音色）

## 三、中国本地化要改什么（核心）

### 3.1 考纲本地化：从"通用问诊"到"中国住培OSCE三考站"

**开源默认：** 通用问诊对话，没有标准化评分表

**我们要改：**
- 对齐中国住培OSCE三考站评分表（病史采集/体格检查/临床思维）
- 按中国住培考核标准设计病例，不是国外病例
- 评分维度按中国规范，不是MIRS

| 维度 | 开源默认（MIRS） | 中国本地化（住培OSCE） |
|------|-----------------|----------------------|
| 分诊判断 | 无 | 有（急诊分级） |
| 病史采集 | 沟通技巧为主 | 关键病史点是否问到（更临床） |
| 重点查体 | 无 | 有（针对主诉的重点查体） |
| 处置决策 | 无 | 有（检查/用药/会诊） |
| 安全意识 | 无 | 有（红旗症状识别） |

### 3.2 病例本地化：从"国外病例"到"中国常见病"

**开源默认：** 基于MIMIC-IV（美国ICU数据），病例偏西方人群

**我们要改：**
- **病例库中国化：** 用中国常见病、多发病（高血压、糖尿病、心梗、脑卒中、消化道出血等）
- **流行病学适配：** 中国人群特点（如高胃癌/肝癌/肺癌发病率、高血压知晓率低等）
- **中医？** 先不做西医为主，未来可加中医病种
- **急诊特色：** 按中国急诊常见场景设计（车祸伤、一氧化碳中毒、心脑血管急症）

### 3.3 语言本地化：英文→中文

**开源默认：** 英文对话，英文评分

**我们要改：**
- **对话全中文：** 病人说中文，学员输入中文
- **医疗术语本地化：** 中文医学术语，不是直译英文
- **方言预留：** MVP先普通话，未来可加主要方言（粤语/四川话等）
- **UI全中文：** 界面、报告、提示全部中文

### 3.4 合规本地化

**开源默认：** 符合欧美隐私法规（HIPAA等）

**我们要改：**
- **数据安全法：** 数据本地化存储，不出境
- **等保三级：** 按中国医疗信息系统安全等级保护要求
- **个保法：** 学员数据匿名化，训练数据脱敏
- **医疗器械：** 定位"医学教育"而非"诊疗辅助"，不碰二类/三类医疗器械注册

### 3.5 用户习惯本地化

**开源默认：** Web端为主，桌面浏览器

**我们要改：**
- **微信生态：** 小程序优先，学员用微信登录，不用记密码
- **移动端优先：** 学员在手机上练，不是坐在电脑前
- **推送通知：** 微信服务通知，提醒学员"该训练了"
- **中文交互习惯：** 简化操作，不要太复杂的设置

### 3.6 教学管理本地化

**开源默认：** 个人练习工具，没有班级管理

**我们要改：**
- **基地管理后台：** 学员管理、排班、班级看板（中国住培基地的管理需求）
- **带教老师工作流：** AI初评+老师复核，符合中国教学习惯
- **考核模式：** 模拟结业考核，不是随便练

## 六、为什么这个思路靠谱

1. **快：** 1-3个月能出MVP，不是6-12个月
2. **稳：** 开源底座经过顶会验证，病人对话质量有保证
3. **准：** 我们专注本地化（中国考纲+病例+合规），这才是差异化
4. **省：** 不需要养NLP团队，只需后端+前端+医学顾问

**一句话：用开源把"病人对话"这个硬骨头啃完，我们把精力全部放在"中国住培本地化"和"教学管理"这两个开源做不了的事情上。**
