## 三、新发现的商业机会

### 3.1 医学编码MCP Server
- **为什么重要：** 药企、商保、CRO都需要把患者诊断/检查操作标准化成编码（ICD-10/CPT）
- **你能怎么用：**
  - 你的随访产品自动把患者诊断转成标准编码
  - 给药企MSL做文献数据提取时，编码标准化
  - 作为独立的MCP工具卖给药企数据团队

### 3.2 实验室报告自动结构化
- **为什么重要：** 患者化验单都是PDF/图片，要结构化才能做数据分析
- **你能怎么用：**
  - 高血压随访产品：患者拍照化验单→自动提取血压、血脂、血糖指标→做趋势分析
  - 给药企做真实世界研究数据提取

### 3.3 细分场景虚拟患者
- **不要做通用患者模拟器**（大厂在做）
- **做细分场景：**
  - 高血压随访沟通训练（给药企医学代表培训用）
  - 减重患者依从性沟通训练
  - 糖尿病足患者随访沟通训练
