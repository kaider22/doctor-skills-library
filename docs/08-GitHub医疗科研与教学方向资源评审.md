## 三、重点项目深评

### 1. OpenEvidence MCP Server（两个实现）
- **为什么重要：** OpenEvidence是你仝学的直接对标产品，估值820亿。现在有人开源了它的MCP接口，可以直接看它怎么实现的。
- **你能怎么用：**
  - 对比你的仝学产品，找差距
  - 直接用它的数据源（PubMed等）做底层
  - MCP Server可以直接集成到你的产品里

### 2. medkit-app（AI患者模拟器）
- **Star：** 333，是教学方向最高星项目
- **为什么重要：** 语音优先的AI患者模拟器，医生培训用。这个方向商业价值高——医学院、规培基地都需要。
- **你能怎么用：**
  - 不做完整产品，做细分场景：比如"高血压患者随访沟通训练"、"减重患者依从性沟通训练"
  - 给药企做医学代表培训工具（怎么和患者聊用药依从性）

### 3. stanfordmed/aimeded
- **为什么重要：** Stanford医学院官方的AI医学教育工具合集，权威。
- **你能怎么用：** 找现成的教学工具和方法，直接参考或集成。
