## 十、你的切入点建议

### 最匹配你资源的3个方向

1. **给药企MSL做文献证据+学术写作工具**
   - 用什么：OpenEvidence MCP + MedPen + PubMed API
   - 付费方：药企医学部/MSL团队
   - 客单价：10-50万/年

2. **高血压随访产品（化验单自动结构化+编码标准化）**
   - 用什么：lab-report-to-fhir-skill + medical-codes-mcp-server
   - 付费方：药企+商保
   - 客单价：按项目/按人头

3. **医学代表患者沟通训练工具**
   - 用什么：medkit-app患者模拟器架构
   - 付费方：药企医学部
   - 客单价：10-30万/项目
