## 五、可直接搭建的技术栈

### 5.1 高血压随访H5

```
前端：H5小程序（微信生态）
后端：FastAPI + PostgreSQL
AI层：DeepSeek/通义千问 API + RAG
数据源：
  - PubMed API（文献指南）
  - DailyMed API（药品说明书）
  - ClinicalTrials.gov API（临床试验匹配）
随访引擎：定时任务 + 微信模板消息 + AI语音外呼
数据输出：患者分层报告（给药企/商保）
```

### 5.2 仝学循证问答MVP

```
前端：Web端
后端：FastAPI + Elasticsearch
AI层：
  - 文献检索：PubMed E-utilities API
  - 证据分级：GRADE框架（规则引擎）
  - 问答：大模型 + RAG（内部知识库+外部API）
数据源：
  - PubMed（免费）
  - ClinicalTrials.gov（免费）
  - FDA DailyMed（免费）
  - 自建指南库（手动录入NCCN/AHA/ADA等）
```
